# Этап 3: сайт, иконки, ссылки

## Сделано

- `tools/build_site.py`: в `PAGES` добавлены «Ферма у реки» (`plan/ferma.html` → `docs/ferma.html`, иконка `ferma`, цвет `#2f4a2a`) и «Оборона таблицы» (`plan/oborona.html` → `docs/oborona.html`, иконка `oborona`, цвет `#0e1d27`). На главной `docs/index.html` две новые карточки после арены, обновлён вводный абзац и README сайта. Манифесты и страницы попали в список предзагрузки сервис-воркера.
- Иконки PWA `tools/icons/ferma-{180,192,512}.png` и `oborona-{180,192,512}.png` рисуются скриптом `tools/make_icons.py` (PIL, суперсэмплинг 4×, ключевые формы в центральных 80 % под maskable). Старые иконки не трогались.
- `prompts/README.md`: колонка «Готовая игра» со ссылками на исходник и адрес на сайте; «Блокоград» помечен как ещё не сделанный. Главный `README.md`: абзац про две игры со ссылками на сайт, `plan/`, `prompts/` и `progress/`, строка в составе папок.
- `docs/` пересобран финальной версией игр (`python3 tools/build_site.py`), проверен headless-браузером: `index.html`, `ferma.html`, `oborona.html`, `trenazhery.html` открываются без ошибок консоли, у каждой страницы свой манифест, в `sw.js` обе игры в списке `CORE`.

- Включить GitHub Pages для ветки, если ещё не включено (см. `docs/README.md`): после этого игры доступны по `https://alexander-hdl.github.io/CMFL/ferma.html` и `…/oborona.html`.
- Проверить на настоящем планшете: касания, перо XP-PEN, частота кадров (в headless-рендере у «Обороны» раз в ~1,5 с видны пики кадра около 200 мс, похоже на рендер без GPU), длину сессии живым ребёнком.
- Публикация как артефактов claude.ai с хранилищем db: код зеркалирует сохранение в `ferma/save` и `oborona/save`, но без `window.claude` проверить это можно было только фейком.

## Найдено и решено

- В `plan/ferma.html` нет переменной `--bg`, цвет темы для манифеста взят из фона `html/body` (`--frame`).
- Промежуточная сборка `docs/` была сделана, пока игры ещё правились; её откатили и пересобрали в конце, чтобы в `docs/` не попала полуготовая версия.
- Сборщик режет исходник по `</style>`, поэтому в обеих играх ровно один `<style>` и один `<script>`, как требуют конвенции.
