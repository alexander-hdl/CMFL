# Английские буквы — ручная проверка

Что нельзя проверить автотестами: как звучат названия букв голосом настоящего устройства, письмо пером и пальцем, вид на планшете.

- **Где открывать:** на claude.ai — https://claude.ai/artifact/VWWuDbAsZXkaUSrAkvTdkT; сайт — https://alexander-hdl.github.io/CMFL/angliyskie-bukvy.html. «Трудные» буквы и настройки хранятся только в этом браузере.
- **Что понадобится:** планшет сына (iPad или Android), компьютер с пером XP-PEN, если есть; около 15 минут, звук включён.
- **Как отмечать:** в колонке «Результат» ставьте ✓ или ✗ с короткой заметкой (что услышали или увидели, на каком устройстве), в «Дате» — день проверки.

## Планшет

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 1 | На вкладке «Алфавит» нажмите по очереди A, E, G, J, R, W, Z | Звучат названия букв по-английски: «эй», «и», «джи», «джей», «а», «дабл-ю», «зед»; не русские звуки и не «а» вместо «эй» у буквы A | | |
| 2 | Переключите «американское» и нажмите R и Z | Звучат «ар» и «зи»; если голос тот же британский, отметьте ✗ и что за устройство | | |
| 3 | Вверху страницы есть красная рамка «не нашёлся английский голос»? | Рамки нет. Если есть, впишите устройство и браузер | | |
| 4 | «Карточка» → «По алфавиту» при фильтре «согласные 20» | Карточки сами идут B, C, D, F… с названием и паузой; «Стоп» останавливает | | |
| 5 | «Диктант» → «Начать диктант»: напишите пальцем B и b на линейках, нажмите «Проверить» | Палец пишет, страница не прокручивается; ниже появляется образец Bb на таких же линейках, название «би» | | |
| 6 | Сравните образцы букв с прописями сына (особенно заглавные G, Q, Z, F, I, J) | Буквы похожи на школьные; впишите, какие отличаются, — их можно будет поправить или предупредить | | |
| 7 | Пройдите диктант, отметив 2 буквы «Ошибся», закройте браузер полностью и откройте снова | На «Алфавите» у этих букв красная точка, кнопка «трудные» в диктанте выбирает их | | |

## Перо XP-PEN и ноутбук

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 8 | «Карточка» → «Обведи пальцем или пером»: обведите бледную букву пером с разным нажимом | Линия идёт за пером без разрывов, при сильном нажиме толще | | |
| 9 | На ноутбуке в «Карточке» нажимайте стрелки ← → и пробел | Стрелки листают буквы с названием, пробел повторяет название | | |

## Без сети (сайт)

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 10 | Откройте страницу при сети, включите режим полёта, закройте и откройте снова | Страница открывается, письменные буквы прописью (а не обычным шрифтом), названия звучат (голос устройства работает без сети не везде — впишите, что было) | | |
