# «Блокоград»: проверка для родителя

Адрес игры: https://alexander-hdl.github.io/CMFL/blokograd.html, на claude.ai: https://claude.ai/artifact/6DiGYA6FVP3AJzrWKQjhSw

Как проверять: планшет держите боком. Сначала сын играет один игровой день с утра до «Спать», а вы молча смотрите и засекаете время (около 15 минут, пункты 1–6 по ходу его игры). Остальные пункты взрослый проходит сам, это ещё около 15 минут. Пункты идут по важности. В колонку «Результат» пишите ✓ или ✗ и коротко, что случилось.

Уже известно, отмечать не нужно: на экране шириной с планшет кнопки ♪ и ⚙ уходят во второй ряд; на заставке написано «Остров…», хотя островов семь; на заставке «Блокоград спит» дневное небо и подсказка про планшет; пауза ❚❚ останавливает солнце без предела; текст в дневнике показывается так, как его написал сын, даже с ошибками.

## Планшет пальцем

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 1 | Открыть игру, нажать «Играть» и дать сыну без объяснений. Смотреть первые 2–3 минуты, не подсказывать | Сын сам водит человечка касанием, находит «Задания жителей» и берёт задание. Записать, где застрял и не мешает ли ему количество текста | | |
| 2 | Стройка: взять чертёж вида 6 × 8, протянуть пальцем рамку по земле от угла до угла, взять блоки из сундука цифрами или стопками по 10. Один раз взять меньше, чем нужно | Рамка тянется за пальцем с подписями сторон; при нехватке недостающие клетки обведены, лишние блоки возвращаются; слова «неверно» нет | | |
| 3 | Верстак: собрать слово из частей (вроде лес + ник), в «Молоте ударения» попробовать закрыть «в_да» | Слово собирается из частей; «в_да» закрывается только проверочным словом «во́ды»; слов с ошибками на экране нет | | |
| 4 | Лавка Ильяса: купить товар монетами и купюрой, продать камень или брёвна. Один раз дать купюру меньше цены | Купюра меньше цены не принимается; сдачу считают вместе, от цены вверх; монеты прибавились после продажи | | |
| 5 | Дождаться заката, у одного дома не ставить фонарь. Подойти человечком к гремлину. Утром посмотреть на дом | Гремлин приходит к неосвещённому дому и откусывает кирпич; убегает, когда подходит человечек, никто не погибает и не страшно; утром Фёдор просит починить дыру | | |
| 6 | Сын играет до заката, смотрит итоги дня и нажимает «Спать». Засечь время от «Играть» | День около 12 минут по солнцу, затем итоги и заставка «Блокоград спит. День N закончен. Город отдыхает до завтра». Записать минуты (цель 10–15) | | |
| 7 | Удерживать ⚙ пальцем две секунды: один раз в игре, один раз на заставке «Блокоград спит». Ещё раз: палец чуть съезжает во время удержания | Открывается экран для взрослого, и в игре, и поверх заставки. Записать, сработало ли, когда палец съехал | | |
| 8 | На экране для взрослого строку «Игровых дней за один настоящий день» поставить на 2 (+). Закрыть. Сыграть второй день до «Спать», обновить страницу | После первого дня на заставке кнопка «Ещё один день»; после второго только отдых, обновление страницы не помогает. На следующий календарный день открытая вкладка сама показывает «Играть» в течение минуты | | |
| 9 | Походить по большому острову, повернуть и наклонить камеру (👁), включить и выключить звук кнопкой ♪ | Без рывков и без чёрного экрана; если экран всё же почернел, игра сама перезагружается и всё на месте. Звук слышен, ♪ его выключает | | |
| 10 | Построить что-нибудь и купить в лавке, обновить страницу посреди дня | Постройка, монеты и рюкзак на месте, день продолжается | | |
| 11 | Повернуть планшет вертикально, сделать пару ходов, повернуть обратно | Просьбы повернуть нет; записать, можно ли так играть и не прячутся ли кнопки. Боком всё как было | | |
