# Блокоград

[claude.ai/artifact/6DiGYA6FVP3AJzrWKQjhSw](https://claude.ai/artifact/6DiGYA6FVP3AJzrWKQjhSw). Сделана по заданию [`../../prompts/fable-blokograd.md`](../../prompts/fable-blokograd.md): каждая механика сама является учебным действием, викторин нет. Архипелаг из семи островов 128 × 128 (Блокоград, Скалы, Лес, Пески, Луга, по кораблю Снега и Черепахи), свой человечек (ходит по касанию, стрелкам или экранным кнопкам; второй режим — свободная камера) и жители со своей работой на каждом острове. Стройка рамкой — умножение и площадь (чертежи вида 6 × 8, две грядки, забор «в длину и в высоту», «разложи 48 блоков в 6 рядов», мосты между островами «6 в длину и 3 в ширину»; блоки берутся из сундука цифрами или стопками по 10, сундук можно пополнять из своего рюкзака, недостающие клетки обводятся, лишние возвращаются; подсказка «Разрезать рамку» уходит после двух дней без неё). Работа у жителей островов — те же рамки за плату, по одной в день у каждого. Корабль на Снега — судовой журнал: часы × мили в час. Верстак — слова из частей (рецепты вида лес + ник = лесник, части добываются из руды), «Молот ударения» для безударных гласных (в_да закрывается только проверочным во́ды), «Редкие чертежи» для словарных слов (посмотри 3 секунды, закрой, собери из букв, дырки подсвечены), таблички -тся/-ться (сначала вопрос, потом окончание). Торговля — весь каталог лавки Ильяса и скупка камня и брёвен: монеты и купюры без сдачи, сдача «считаем вместе» от цены вверх, «хватит ли денег», «сколько я должен за 4 штуки по 2». На закате к неосвещённым домам приходят гремлины и откусывают по кирпичу: их прогоняют, подойдя человечком (никого не убивают), защищают фонарём с маслом из лавки, а утром Фёдор просит починить дыры купленным кирпичом. День в игре — 12 минут по солнцу без цифр, ночью экран итогов, после которого «Спать» ведёт на экран «Блокоград спит»: по умолчанию один игровой день за настоящий день, взрослый меняет это (1–3) строкой «Игровых дней за один настоящий день» на своём экране, перезагрузка лимит не обходит; повторение через 1, 3, 7, 14 дней; камера поворачивается на 45° и наклоняется до вида сверху (кнопка 👁, для мостов встаёт сверху сама); дневник ребёнка (кнопка 📓): мысли и пожелания, на которые родитель отвечает с экрана для взрослого, кнопка «Отправить родителям» шлёт записи через почту или мессенджер; экран для взрослого (удерживать ⚙ две секунды) с точностью по типам, трудными примерами, дневником, переносом сохранения и своим списком слов.
