## Как работать

- Исходник: `apps/komiksy/komiksy.html` (~51 КБ, один файл, формат артефакта без `<html>/<head>/<body>`). Манифест: `apps/komiksy/app.json` (`out: komiksy.html`, `icon: comics` — не менять).
- Сборка сайта: `python3 tools/build_site.py`, затем `docs/komiksy.html`.
- Тесты: `node tools/test_app.mjs komiksy` запускает `testCommand` из `app.json` (`node apps/komiksy/tests/eksport.test.cjs`), около 10 с. Отладочного интерфейса `window.OT` нет, тест работает кнопками и мышью.
- Слои: четыре canvas (`#c-bg` белый фон, `#c-paint` рисунок, `#c-frames` рамки, `#c-bub` облачка) и HTML-слой `#bubbles` с `textarea`. Логический размер страницы задаёт `LAYOUTS[...]` (`L.W × L.H`, для 3 кадров 1500×620).
- Хранилища:
  - черновик: `localStorage["comic-draft-v1"]` (раскладка, название, облачка, рисунок как PNG data URL), запись с задержкой после штриха;
  - альбом на claude.ai: `window.claude.use("db")`, коллекция `comics` (`title, d, ts, asset, layout, checked`) + `use("assets")` для PNG; скачивание через `use("downloads")`;
  - альбом вне claude.ai (`LOCAL`): IndexedDB `komiksy`, версия 1, хранилище `comics` (`id` с префиксом `l`, PNG как Blob); скачивание через `<a download>` с транслитерацией имени.
- Журналов этапов нет. Скриншоты: `dev/shots/` (01 старт 1280×800, 02 штрихи пером, 03 шаг «Проверь 2 слова», 04 альбом).

## Принятые решения

- В облачках `autocorrect="off"`, `autocapitalize="off"`, `spellcheck="false"`: слова остаются такими, как он их написал (подпись под редактором), иначе ошибки не увидеть и не найти самому.
- Шаг «Проверь 2 слова» перед сохранением: он сам выбирает 2 слова из облачков и сверяет по буквам; связан с ошибками в диктантах (пропуски букв, безударные). Сохранить можно и без выбора слов — по коду, причина не записана.
- Ошибки красным не исправляются, хвалят за идею и за найденные слова (подсказка взрослому в шаге проверки): комикс — хобби, а не урок почерка.
- Выбранные для проверки слова сохраняются с комиксом (`checked`) и видны в альбоме («проверил: …»).
- Альбом на claude.ai живёт в хранилище артефакта (db + assets), вне claude.ai — только в IndexedDB этого браузера; синхронизации между устройствами на сайте нет. Причина: на сайте нет `window.claude` (`85dc59d`); страница предупреждает, что при очистке данных браузера альбом пропадёт.
- Имя скачиваемого файла транслитерируется: некоторые браузеры отбрасывают кириллицу в имени (комментарий в коде).
- Нажим учитывается только у карандаша и только для `pointerType === "pen"`; мышь и палец рисуют средней толщиной (нажим 0,5).
- Отсечения ладони в коде нет: любой `pointerdown` с `button === 0` (в том числе палец) рисует; по коду, причина не записана (см. «Открытые замечания»).
- Штрих обрезается рамкой кадра (`clip` по панели), рисовать между кадрами нельзя; заливка тоже в пределах кадра.
- Картинка для экспорта собирается из готовых слоёв (белый фон, `c-paint`, `c-frames`, облачка), а не перерисовкой рамок. Причина: `drawFrames` очищает холст (`ca10e2a`).

## Подводные камни

- **`drawFrames(g)` начинает с очистки холста.** Вызов на холсте экспорта после фона и рисунка стирает их — это и был баг экспорта. Для экспорта рамки копируются со слоя `#c-frames`.
- **Кнопки «Скачать картинку» (`#dl`) и «Сохранить в альбом» (`#save`) живут на шаге «Проверь 2 слова».** Тест сначала нажимает `#to-check` и ждёт видимого `#dl`.
- **Альбом вне claude.ai только в IndexedDB** (`komiksy`, v1, `comics`). Режим выбирается по наличию `window.claude.use` (`LOCAL`): мок `window.claude` в тесте переключит страницу на `db` + `assets`, и IndexedDB использоваться не будет.
- **`window.OT` нет**, а `tools/test_app.mjs` без него не дождётся загрузки. Поэтому тест запускается через `testCommand` своим скриптом: он сам оборачивает исходник в документ и открывает его, сборка для него не нужна, проверяется исходник, а не `docs/`.
- Мышь в Playwright даёт `pointerType: "mouse"` и нажим 0,5; нажим проверяется только синтетическими событиями пера.
- Черновик хранит рисунок как PNG data URL в `localStorage`, запись обёрнута в `try`: если не влезет, черновик молча не сохранится (по коду). Упирается ли шестикадровый рисунок в лимит браузера — предполагаю, что может; не проверялось.
