# Студия комиксов: ручная проверка

Что нельзя проверить автотестами: нажим и кнопка настоящего пера, ладонь на экране, клавиатура планшета, куда попадает скачанный файл и альбом после закрытия браузера.

- **Где открывать:** на claude.ai — https://claude.ai/artifact/78TnnhbtiWef319zJ2SQM8 (альбом общий для всех устройств с вашим аккаунтом); сайт — https://alexander-hdl.github.io/CMFL/komiksy.html (альбом только в этом браузере).
- **Что понадобится:** компьютер с пером XP-PEN (в настройках Windows включён Windows Ink), iPad, ноутбук с мышью; около 25 минут. Лучше рисовать вместе с сыном: он быстрее заметит, что перо «не слушается».
- **Как отмечать:** в колонке «Результат» ставьте ✓ или ✗ с короткой заметкой (что увидели, на каком устройстве), в «Дате» — день проверки.

## Перо XP-PEN

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 1 | Выберите «Карандаш» и проведите одну линию, сначала едва касаясь, потом сильно нажимая | Линия тонкая при слабом нажиме и толстая при сильном; у «Фломастера» толщина ровная | | |
| 2 | Нарисуйте пару линий, затем переверните перо ластиком (или нажмите кнопку ластика на пере) и проведите по ним | Линии стираются, как инструментом «Ластик», без переключения кнопки на экране | | |
| 3 | На сенсорном экране рисуйте пером, положив ладонь на экран, как на бумагу | Ладонь не оставляет следов (защиты от ладони в студии нет: если следы есть, отметьте ✗ и где) | | |
| 4 | Нарисуйте замкнутый круг внутри кадра, выберите «Заливка» и коснитесь внутри круга | Закрашивается только внутри круга, цвет не выходит за кадр | | |
| 5 | Нарисуйте комикс, нажмите «Проверить и сохранить»: на шаге «Проверь 2 слова» сын выбирает два слова из облачков, затем «Сохранить в альбом» | Выбранные слова видны по буквам; после сохранения надпись «Сохранено в альбом…», в «Мой альбом» под комиксом «проверил: …» | | |

## iPad пальцем

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 6 | Нажмите «+ Реплика» и напечатайте с экранной клавиатуры «малако пришол» | Слова остаются ровно такими: не исправляются, не подчёркиваются красным, первая буква не становится заглавной | | |
| 7 | Порисуйте пальцем в кадре, особенно у краёв страницы | Палец рисует, страница не прокручивается и не увеличивается | | |
| 8 | Нажмите «Скачать картинку» в Safari, затем откройте приложение «Файлы» → «Загрузки» | Там лежит картинка с латинским именем; в ней видны рисунок, белый фон, рамки и облачка (впишите, куда файл попал на самом деле) | | |
| 9 | Сохраните комикс в альбом, закройте Safari полностью (смахните из списка приложений) и откройте студию снова | В «Мой альбом» комикс на месте вместе с рисунком, а не пустые рамки | | |
| 10 | Нажмите «Весь экран», порисуйте, выйдите обратно | Студия занимает весь экран и рисует; если iPad не разворачивает на весь экран, ничего не ломается (впишите, что было) | | |

## Ноутбук с мышью

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 11 | Нарисуйте мышью, перетащите облачко, его хвостик и уголок размера; потом «Отменить» и Ctrl+Z | Мышь рисует средней толщиной, облачко двигается и растягивается, отмена убирает последние шаги по одному | | |
| 12 | Начните рисунок, не сохраняя закройте вкладку и откройте студию снова | Незаконченный рисунок, название и облачка на месте | | |

## Без сети (сайт)

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 13 | Откройте сайт при сети, затем включите режим полёта, закройте вкладку и откройте студию снова | Студия открывается, рисует и сохраняет в альбом; альбом на месте | | |
