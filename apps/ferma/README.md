# Ферма у реки

Спокойная ферма в духе Stardew Valley и Harvest Moon для сына 9 лет, сделана по заданию [`prompts/fable-ferma.md`](../../prompts/fable-ferma.md). Учебная часть — сама жизнь фермы, викторин нет: время двигается только от действий, и по часам со стрелками надо успеть в магазин до закрытия; семена пакетиками по 10 дают деление с остатком, которое проверяет грядка; на рынке сдачу отсчитываешь сам; урожай взвешиваешь гирями; заказы соседей — записки, которые надо внимательно прочитать. Есть курятник с яйцами в коробках по 10, календарь на стене, мерная лента, амбарная книга, копилка на постройки, лодка, дела дня. Подстройка по навыкам (точность за последние 20 попыток), экран для взрослого с полосами навыков и примерами ошибок. Программа 3 класса: часы и длительность, деньги и сдача, умножение и деление с остатком, масса, задачи в 1–2 действия, внимательное чтение.

## Файлы

- `ferma.html` — игра, один файл; отладочный интерфейс `window.FERMA` (`state()`, `api`, `ready`).
- `tests/` — приёмочные и модульные тесты: `node tools/test_app.mjs ferma` из корня (`FERMA_FAST=1` — около 3 минут, полный прогон около 5; 1118 проверок). Запускатель `tests/_harness.cjs` открывает исходник напрямую.
- `dev/` — проектный документ `00-proekt.md`, отчёты по этапам `01-prototip.md` и `02-polnaya-igra.md`, конвенции ветки `konvencii-vetki.md`, текущее состояние `STATUS.md`.

Игра сделана в ветке `claude/admiring-hamilton-7ulcy6` параллельной сессией и перенесена в `apps/ferma/` целиком. Пути в журналах записаны до переезда: `plan/ferma.html` теперь `apps/ferma/ferma.html`, `tools/tests/ferma.test.cjs` теперь `tests/ferma.test.cjs`, `progress/ferma/` теперь `dev/`.
