# Общие конвенции для игр «Ферма у реки» и «Оборона таблицы»

Этот файл читают все агенты (аналитики, кодеры, ревьюверы) перед работой. Задания игр лежат в `prompts/fable-ferma.md` и `prompts/fable-oborona-tablicy.md`, общие принципы учебных игр — в `prompts/README.md`.

## Где что лежит

| Что | Путь |
|---|---|
| Исходник игры (формат артефакта claude.ai) | `plan/ferma.html`, `plan/oborona.html` |
| Собранная страница для GitHub Pages | `docs/ferma.html`, `docs/oborona.html` (собирает `tools/build_site.py`, руками не править) |
| Приёмочные и модульные тесты | `tools/tests/ferma.test.cjs`, `tools/tests/oborona.test.cjs` |
| Проектная документация и отчёты по этапам | `progress/ferma/*.md`, `progress/oborona/*.md` |
| Иконки для PWA | `tools/icons/ferma-{180,192,512}.png`, `tools/icons/oborona-{180,192,512}.png` |

## Формат исходника (как у `plan/trenazhery.html`)

- Файл начинается с `<title>…</title>`, затем `<link>` на Google Fonts (Nunito и Russo One уже используются в арене), затем один `<style>…</style>`, затем разметка `<body>` без тегов `<html>/<head>/<body>`, затем один `<script>`. Сборщик режет файл по `</style>` и оборачивает в полный документ.
- Никаких внешних картинок, звуков и библиотек: всё процедурно на canvas 2D, звук через WebAudio с выключателем.
- Язык: `lang="ru"` ставит сборщик. Все тексты по-русски, с буквой ё, без орфографических ошибок. Никогда не показывать слово с ошибкой.
- Все действия ребёнка — крупные кнопки (от 48 px), контрастный крупный текст, без вспышек и тряски. Работает на 1024×768 (планшет) и 1366×768 (ноутбук), касание, перо, мышь (Pointer Events).
- `@media (prefers-reduced-motion: reduce)` выключает анимации.

## Хранилище

- `localStorage` с префиксом `ferma-` / `oborona-`: один ключ `…save` с JSON всего состояния плюс версия схемы `v`. При смене схемы — миграция, а не потеря прогресса.
- Если есть `window.claude` с `use("db")` — дублировать сохранение в документ `ferma/save` / `oborona/save` по образцу арены (`plan/trenazhery.html`, функция около строки 4564). Без `window.claude` всё работает из localStorage.
- Реальная дата для лимита игровых дней/уровней в сутки: строка `YYYY-MM-DD` по локальному времени.

## Тестируемость

- Вся логика без DOM (согласование числительных, сдача, весы, арифметика времени, генерация волн, коробки Лейтнера, подбор заданий) живёт в чистых функциях и доступна тестам через `window.FERMA` / `window.OBORONA`: объект вида `{ version, logic: {…чистые функции…}, state(), api: {…действия игры, вызываемые без клика…}, render() }`.
- Тесты — обычные скрипты node с Playwright: `node tools/tests/ferma.test.cjs`. Браузер уже установлен (`/opt/pw-browsers`), пакет берётся через `require("playwright")` (CommonJS, ESM-импорт не находит пакет). Страницу открывать как `file://…/plan/ferma.html` (без html-скелета браузер всё равно отрисует) или собранную `docs/ferma.html`.
- Тест завершает процесс кодом 1 при любом провале и печатает список проверок. Приёмка из задания игры должна быть покрыта тестами один к одному.
- Для ручного осмотра ревьювер делает скриншоты в scratchpad, не в репозиторий.

## Согласование числительных

Единая функция `plural(n, one, few, many)` (как в арене: 1 яблоко, 2 яблока, 5 яблок, 11 яблок, 21 яблоко, 22 яблока, 25 яблок) и словарь форм для всех существительных игры. Тесты на 1, 2, 5, 11, 21, 22, 25, 100, 101, 111.

## Запрещено (из задания)

Случайные награды и сундуки, бонусы за ежедневный вход, сгорающие серии, реклама, покупки, бесконечная игра без конца дня/ночи, таймеры в момент ответа, всплывающие викторины, названия и персонажи оригинальных игр.

## Этапы и отчёты

1. **00 — проект**: аналитик (Opus) пишет `progress/<игра>/00-proekt.md`: архитектура, модель данных, экраны, список чистых функций с сигнатурами, план прототипа и полной игры, список приёмочных тестов, риски.
2. **01 — прототип**: кодер (Sonnet) делает прототип по п. 1 «Порядок работы» задания + тесты; ревьювер (Opus) проверяет и пишет замечания; кодер исправляет. Отчёт `01-prototip.md`.
3. **02 — полная игра**: п. 2 «Порядок работы». Отчёт `02-polnaya-igra.md`.
4. **03 — сайт**: сборка в `docs/`, иконки, ссылки с главной и из README. Отчёт `progress/03-sajt.md`.

Каждый отчёт содержит три раздела: **Сделано**, **Осталось**, **Найдено и решено** (проблемы, решения, открытые вопросы).
