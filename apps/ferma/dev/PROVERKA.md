# «Ферма у реки»: проверка для родителя

Адрес игры: https://alexander-hdl.github.io/CMFL/ferma.html

Как проверять: планшет держите боком. Сначала сын играет одно занятие с самого начала, а вы молча смотрите и засекаете время (около 15 минут, пункты 1–7 по ходу его игры). Остальные пункты взрослый проходит сам, это ещё около 15 минут. Пункты идут по важности. В колонку «Результат» пишите ✓ или ✗ и коротко, что случилось.

Если игру уже открывали, перед пунктом 1 начните с нуля: экран для взрослого (пункт 8) → «Начать заново».

Уже известно, отмечать не нужно: окно сдачи с копейками выглядит перегруженным; часы в верхнем углу закрывают крышу дома; полив занимает 10 минут на каждый ряд, а не на всю грядку. Если сын застревает в этих местах, это стоит записать.

## Планшет пальцем

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 1 | Открыть игру и дать сыну без объяснений. Смотреть первые 2–3 минуты, не подсказывать | Утром плашка «Что нового»; сын сам понимает, куда идти: полить грядку, прочитать записку, встретить покупателя. Записать, где застрял | | |
| 2 | По ходу игры спросить сына, сколько времени, по часам со стрелками вверху. Потом коснуться часов четыре раза за один игровой день | Стрелки крупные, сын читает время сам; первые три касания показывают время цифрами, четвёртое — «Сегодня больше нельзя. Смотри на стрелки.» | | |
| 3 | Покупатель у прилавка платит больше цены: отсчитать сдачу монетами пальцем. Один раз положить лишнюю монету, один раз не доложить | Монеты кладутся и убираются касанием; при лишней «Тут лишние … рублей», при нехватке «Не хватает … рублей», слова «неверно» нет; верная сдача принимается | | |
| 4 | Прочитать записку соседа (кнопка «Заказы»), выполнить заказ, один раз нарочно принести не то | Текст записки читается с планшета без увеличения, слов с ошибками нет; сосед сам называет причину отказа (вроде «Я просила красные.»). Записать, читает ли сын записки сам | | |
| 5 | Взвесить урожай гирями для заказа: сначала поставить не те гири, потом верные | Чаши выравниваются только при точной массе, «В мешок» до этого не нажимается; при неверных гирях видно, сколько есть и сколько нужно | | |
| 6 | Опоздать в магазин семян: прийти после 17:00. В субботу прийти на рынок после 12:00 | Дверь закрыта, на ней часы работы «с 9:00 до 17:00»; рынок работает только по субботам с 8:00 до 12:00, после 12:00 закрыт | | |
| 7 | Сын играет, пока игра сама не остановит (два игровых дня, вечером «Спать»). Засечь время | После второго дня «Куры спят, приходи завтра»; ни одного внезапного окна с вопросом. Записать минуты (по прикидке около 7, цель 10–15) | | |
| 8 | Удерживать пальцем кнопку «Взрослым» вверху две секунды, отпустить. Ещё раз: отпустить через секунду | Открывается экран с полосами навыков и строкой «Игровых дней в сутки»; если отпустить раньше, не открывается | | |
| 9 | После «Куры спят» обновить страницу. На следующий календарный день открыть снова | После обновления куры всё ещё спят; на следующий день начинается новый игровой день | | |
| 10 | Полить грядку, запомнить время на часах и деньги, обновить страницу | Время, деньги и политая грядка на месте | | |
| 11 | Походить по ферме и в деревню, закончить любое действие. На экране для взрослого выключить «Звук» | Человечек идёт без рывков; после действия слышен короткий звук «готово»; после выключения тишина | | |
| 12 | Повернуть планшет вертикально, потом обратно | Вертикально плашка «Поверни планшет», игра работает и так; боком всё как было | | |
