# Тренировочная арена: ручная проверка

Что нельзя проверить автотестами: длительность тренировки с живым ребёнком, перо, голос, съёмка, работа без сети и общий прогресс на двух устройствах.

- **Где открывать:** на claude.ai — https://claude.ai/artifact/NUnVhvzy88WsXPZpf4yvSm (с ИИ, прогресс общий для всех устройств с вашим аккаунтом); сайт — https://alexander-hdl.github.io/CMFL/trenazhery.html (без ИИ, прогресс только в этом браузере).
- **Что понадобится:** планшет (пальцем и с пером XP-PEN), телефон для съёмки, ноутбук с мышью; около 40 минут, можно частями. Пункты 1–3 удобно проверить в обычный день, когда сын сам делает «Тренировку дня».
- **Как отмечать:** в колонке «Результат» ставьте ✓ или ✗ с короткой заметкой (что увидели, на каком устройстве), в «Дате» — день проверки.

## Планшет пальцем

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 1 | Сын нажимает «▶ Тренировка дня» и проходит все шаги подряд; засеките время до окна «Всё! Тренировка дня готова 🎉» | Шаги идут по очереди, после каждого появляется кнопка «Дальше»; вся тренировка занимает 7–10 минут (впишите, сколько вышло) | | |
| 2 | На шаге со словами слушайте, как диктуется слово, и нажмите «Послушать ещё раз»; потом на вкладке «Чтение» нажмите «Прочитать вслух» | Слово звучит русским голосом планшета и понятно на слух; если голоса нет, страница пишет, что слова диктует взрослый (впишите, что было) | | |
| 3 | После тренировки дня посмотрите на 💎 в шапке и откройте питомца | Добавилось 10 💎; строка «Сегодня заработано» показывает не больше 30 из 30, даже если в этот день было много занятий | | |
| 4 | В окне питомца откройте «Магазин» и купите вещь или угощение | Гемы списываются по указанной цене; потратить их можно только на питомца, на матчи и экран обменять негде | | |
| 5 | Сын нажимает 📝 в шапке, пишет, что подлатать или добавить, и сохраняет; вы на вкладке «Прогресс» пишете ответ в поле «Ответ сыну» | На 📝 у сына появляется значок, в заметке виден «Ответ взрослого: …» | | |
| 6 | Пройдите пальцем по всем пяти вкладкам и нажмите кнопки в каждой | Каждая кнопка нажимается с первого раза, без промахов в соседнюю (маленькие крестики в списке дел «Матчей» — известная мелочь) | | |
