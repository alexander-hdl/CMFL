# План: планшет и диктанты — ручная проверка

Что нельзя проверить автотестами: страница на настоящем телефоне, копирование в буфер, тёмная тема, общие записи на телефоне и ноутбуке, работа без сети.

- **Где открывать:** на claude.ai — https://claude.ai/artifact/LeApqezzcT228szk3Jidf2 (отметки и дневники общие для всех устройств с вашим аккаунтом); сайт — https://alexander-hdl.github.io/CMFL/plan.html (записи только в этом браузере).
- **Что понадобится:** телефон (iPhone с Safari и, если есть, Android с Chrome), ноутбук с экраном около 1280×800; около 20 минут. Проверочные записи потом можно удалить.
- **Как отмечать:** в колонке «Результат» ставьте ✓ или ✗ с короткой заметкой; если проверяли на двух телефонах, пишите через косую черту: «iPhone ✓ / Android ✗ кнопки мелкие». В «Дате» — день проверки.

## Телефон

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 1 | Раздел «Недели»: в поле «Начали план» выберите дату, отметьте 2–3 пункта, закройте вкладку и откройте страницу снова | Открывается календарь телефона; после выбора видна текущая неделя; отметки на месте, счётчик «… из 51» и полоска выросли | | |
| 2 | «Дневник диктантов»: дата, «Слов в диктанте», кнопками «+» и «−» число ошибок каждого вида (пропуски букв, безударные, словарные, -тся/-ться, другие), «Сохранить запись» | Кнопки нажимаются пальцем без промахов; запись появляется в «Все записи», таблица листается пальцем вбок | | |
| 3 | Добавьте вторую запись и посмотрите график и плитки; коснитесь пальцем столбика графика | Ошибки показаны на 100 слов, плитки «было → стало»; у столбика появляется подсказка с числами | | |
| 4 | Нажмите «Скопировать сводку для логопеда» и вставьте в мессенджер | Вставляется вся сводка без имени ребёнка; если копирование не сработало, текст выделен на странице и кнопка пишет «Текст выделен — скопируйте» | | |
| 5 | «Дневник открытий»: что пробовал, до двух типов интереса, «😍 Хочу ещё», признаки силы, «Сохранить запись» | Запись появляется, график «Куда тянет» обновляется | | |
| 6 | Прокрутите чипы наверху пальцем вбок до «Логопед» и нажмите; затем листайте страницу вниз | Страница переходит к разделу; полоска с чипами остаётся сверху и не закрывает заголовок | | |
| 7 | Включите тёмную тему телефона и откройте страницу | Текст читается, графики и плитки видны на тёмном фоне, нет белого текста на белом | | |

## Ноутбук с мышью

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 8 | Откройте страницу на ноутбуке 1280×800 и попробуйте мышью дойти до чипов «Фразы» и «Логопед» | Все девять чипов видны или до них можно добраться (сейчас известно, что «Логопед» не виден: отметьте, как есть) | | |
| 9 | В «Дневнике диктантов» перейдите по ссылке на общую сводку в тренажёрах | Открывается арена на вкладке «Прогресс», куда сводку можно вставить | | |
