# Оборона таблицы

(защита крепости, где единственное оружие — таблица умножения): враг несёт число на щите, победить его можно только лучом между двумя башнями с таким произведением; над каждым лучом всегда запись «7 × 8 = 56». Шесть земель от двоек и пятёрок до двузначных: железные боссы («Трудные пятнадцать») режутся на лёгкие примеры (56 − 35 = 21), земля деления с заранее стоящими башнями, подготовка без таймера, пауза в любой момент. Волны собираются по коробкам Лейтнера (70 % знакомых, 20 % на повторение, 10 % новых) и учитывают путаницы вроде «56 ↔ 48»; после трёх уровней крепость закрывается на ночь, лимит уровней в день ставит взрослый. Экран для взрослого (удержание кнопки 2 секунды): карта таблицы по коробкам, точность и время, трудные факты, настройки. Исходник в [`oborona-tablicy.html`](oborona-tablicy.html), в автономном сайте — `oborona-tablicy.html` на сайте; задание, по которому сделана игра, — [`../../prompts/fable-oborona-tablicy.md`](../../prompts/fable-oborona-tablicy.md), рабочий журнал — [`dev/`](dev/00-plan.md).

## Файлы

- `oborona-tablicy.html` — игра, один файл.
- `tests/` — автотесты Playwright: `node tools/test_app.mjs oborona-tablicy` из корня (96 проверок, около 125 с; `--grep текст`, `--shot`). Тесты «Сайт» сравнивают `docs/` с исходником, поэтому перед ними нужен `python3 tools/build_site.py`.
- `dev/` — рабочий журнал: план, архитектура с отладочным интерфейсом `window.OT`, отчёты по этапам, финальное ревью с таблицей требований и ручными проверками для родителя, скриншоты в `dev/shots/`.

Пути в журналах записаны до переезда в `apps/`: `plan/oborona-tablicy.html` теперь `apps/oborona-tablicy/oborona-tablicy.html`, `tools/tests/oborona/` теперь `tests/`, `dev/oborona-tablicy/` теперь `dev/`.
