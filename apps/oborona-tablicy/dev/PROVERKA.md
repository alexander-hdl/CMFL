# «Оборона таблицы»: проверка для родителя

Адрес игры: https://alexander-hdl.github.io/CMFL/oborona-tablicy.html

Как проверять: планшет держите боком. Сначала сын играет одно занятие с самого начала, а вы молча смотрите и засекаете время (около 15 минут, пункты 1–2). Остальные пункты взрослый проходит сам, это ещё около 15 минут. Пункты идут по важности: если времени мало, остановитесь на любом. В колонку «Результат» пишите ✓ или ✗ и коротко, что случилось.

Подсказка на первом уровне видна, только пока первый уровень ни разу не пройден. Если игру уже открывали, перед пунктом 1 сбросьте прогресс: экран для взрослого (пункт 3) → «Сбросить прогресс».

Уже известно, отмечать не нужно: «Дальше» после уровня без трёх звёзд повторяет тот же уровень; нижняя башенка крепости нарисована крышей вниз; надпись над врагом иногда закрывает цифру башни; «Сбросить прогресс» обнуляет и счётчик уровней за сегодня.

## Планшет пальцем

| № | Что сделать | Что должно быть | Результат | Дата |
|---|---|---|---|---|
| 1 | Дать сыну планшет на титуле без объяснений: «Играть» → карта → первая земля → первый уровень. Смотреть первые 2–3 минуты, не подсказывать | Сын сам ставит цифру на серый круг и тянет луч по строке внизу («Перетащи цифру снизу на серый круг», «Коснись башни, потом башни за дорогой»), затем жмёт «В бой!». Записать, где застрял | | |
| 2 | Сын играет уровни подряд, пока игра сама не остановит. Засечь время от «Играть» до конца | Ни разу нет окна с вопросом и вариантами ответа; после третьего уровня «Крепость закрывается на ночь». Записать минуты (цель 10–15) и не смутили ли сына две колонки на экране ночи | | |
| 3 | На карте мира удерживать пальцем ⚙ в правом верхнем углу две секунды, отпустить. Потом «Назад». Ещё раз: отпустить через секунду | Кольцо заполняется, экран «Для взрослого» остаётся открытым после того, как палец убран; «Назад» закрывает. Если отпустить раньше, экран не открывается | | |
| 4 | На экране для взрослого «Уровней в день» поставить 2 кнопкой −. Сыграть два уровня, выбрать третий. Обновить страницу и попробовать снова. Потом вернуть 5 | На третьем уровне «Крепость отдыхает до завтра»; после обновления страницы то же самое | | |
| 5 | В подготовке нарочно не строить луч под одно из чисел на ленте, нажать «В бой!» | Враг доходит до крепости, рядом с воротами на 2 секунды появляется запись вроде «12 = 3 × 4». Она стоит у ворот, а не у края поля, не закрывает цифры и не пугает; слова «неверно» нет | | |
| 6 | Если уже дошли до железных врагов с большим числом: построить луч, после которого остаток не берётся одним лучом (например, против 56 луч 6 × 9) | Луч мигает серым, босс идёт дальше с прежним числом, над ним 2 секунды «Останется 2 — такого луча нет» | | |
| 7 | На экране для взрослого скорость «Быстро». Сыграть два уровня, во время боя перетаскивать цифры и башни на паузе | Враги идут без рывков, при перетаскивании нет следов и задержек, выбранная башня подсвечивает соседей. Допустима короткая задержка в начале волны | | |
| 8 | Слушать звук при постройке и победе. В бою коснуться поля (пауза) → «Звук: выкл» | Звук слышен после первого касания экрана; после «Звук: выкл» тишина | | |
| 9 | Посреди боя обновить страницу (потянуть вниз или кнопка обновления) | Этот уровень начинается заново (так задумано), звёзды и открытые земли на месте | | |
| 10 | Посреди уровня повернуть планшет вертикально, потом обратно | Вертикально просьба «Поверни планшет боком»; боком игра продолжается с того же места | | |
